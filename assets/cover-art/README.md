# Academic cover artwork

Nine distinct decorative cover backgrounds generated with the built-in imagegen tool.
These are visual metaphors for the paper topics, not experimental photographs or evidence.
The prompt set is recorded in `prompts.json`. No publisher logo is used.

Web assets are 600 × 900 JPEGs. The preview embeds each asset once as a data URI; list and reader covers share it. Titles remain live HTML for readability.

## Cosmology (21 October 2026)

`cosmology.svg` is an original decorative vector background: quiet starlight and diffuse curved filaments with a fine grain texture. It is a visual metaphor, not observational data. The homepage embeds it as a data URI and keeps the title in live HTML. Existing photographic covers are unchanged.
